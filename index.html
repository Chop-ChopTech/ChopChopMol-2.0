Powerful Features

Everything You Need for Effortless Editing and Simulation

From simple visualization to complex editing, ChopChopMol provides professional-grade tools accessible from your browser.

3D Visualization

Render molecules with GPU-accelerated instanced meshes. Support for perspective and orthographic cameras with smooth arcball controls.

Atom Selection

Select atoms by clicking, box selection, or chain/residue. Create and manage fragments with comprehensive selection tools.

Measurement Tools

Measure bond lengths, angles, and dihedral angles with precision. Real-time calculations as you interact with structures.

Multiple Styles

Switch between ball-and-stick, space-filling, wireframe, and more. Customize atom colors and rendering quality.

Cloud Storage

Save molecules to the cloud with Firebase integration. Access your work from anywhere with secure authentication.

Tabbed Interface

Work with multiple molecules simultaneously. Drag-and-drop files directly into the application for instant viewing.
